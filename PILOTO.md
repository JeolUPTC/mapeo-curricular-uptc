# Piloto por áreas

Una aplicación estática en una única URL de GitHub Pages o Cloudflare Pages. No requiere servidor de datos ni coordinadores dentro de la aplicación.

1. Abrir el enlace y cargar el JSON de trabajo disponible, o partir de la malla común.
2. Filtrar por el área y trabajar las AC que correspondan. Cada navegador conserva su propia copia.
3. Al terminar, exportar el JSON del área con un nombre nuevo que incluya fecha. Conservar también un respaldo general antes de importar otros archivos.
4. Para reunir el trabajo, cualquier compañero puede usar «Reunir JSON de áreas», revisar los conflictos y descargar la matriz general resultante. Compartir esa copia como nuevo punto de partida.

No editar simultáneamente la misma AC en copias distintas sin acordar qué archivo conservar. Los catálogos de competencias y RA del programa deben coincidir para integrar paquetes. Tras cambiar el catálogo común, compartir el JSON actualizado antes de seguir intercambiando áreas.

Versiones: código etiquetado en Git; archivos JSON conservados por fecha; no sobrescribir entregas. Mantener la URL de publicación estable para no cambiar el almacenamiento del navegador. Respaldar en JSON antes de actualizar la aplicación o cambiar de dispositivo.
